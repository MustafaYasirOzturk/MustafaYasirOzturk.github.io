# Elite Dental Care Website

A modern, elegant dental website with video background and responsive design.

## Features

- Video background on homepage
- Responsive design for all devices
- Smooth scrolling navigation
- Modern CSS animations
- Contact form with validation
- Professional dental services showcase

## Setup

1. Replace the placeholder files with your actual content:
   - `dentist-video.mp4` - Your dental clinic video
   - `dentist-hero.jpg` - Hero section fallback image
   - `dentist-doctor.jpg` - Doctor's photo

2. Customize the content in `index.html`:
   - Clinic name and information
   - Doctor's details
   - Contact information
   - Services offered

## File Structure

```
dentist/
├── index.html          # Main HTML file
├── styles.css          # CSS styling
├── script.js           # JavaScript functionality
├── dentist-video.mp4   # Background video (replace with your video)
├── dentist-hero.jpg    # Hero fallback image (replace with your image)
├── dentist-doctor.jpg  # Doctor photo (replace with your photo)
└── README.md           # This file
```

## Video Background

The website is designed to work with a video background. The video should be:
- MP4 format
- High quality but optimized for web (under 10MB recommended)
- Related to dental care or your clinic
- The CSS will automatically handle fallback to an image if the video fails to load

## Customization

### Colors
The primary color scheme uses:
- Blue (#3498db) for primary actions
- Dark blue (#2c3e50) for text
- Light gray (#f8f9fa) for backgrounds

### Fonts
Uses Google Fonts 'Poppins' for modern typography.

### Responsive Design
Fully responsive with breakpoints at 768px and 480px.

## Browser Support

- Chrome 70+
- Firefox 65+
- Safari 12+
- Edge 79+

## Deployment

Simply upload all files to your web server. Make sure to include the video and image files in the same directory.
